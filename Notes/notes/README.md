Note Guide - FullStackOpen
Overview
This project is part of the FullStackOpen course. The Note Guide is a simple application that allows users to create, view, update, and delete notes. It demonstrates the core concepts of full-stack web development, including RESTful APIs, frontend development with React, and backend development with Node.js and Express.

Features
Create Notes: Users can add new notes to the list.
View Notes: Users can view a list of all notes.
Update Notes: Users can edit existing notes.
Delete Notes: Users can remove notes they no longer need.
Responsive Design: The application is designed to work on various screen sizes.
Tech Stack
Frontend
React: A JavaScript library for building user interfaces.
Axios: For making HTTP requests from the frontend to the backend.
CSS: Styling the user interface.
Backend
Node.js: A JavaScript runtime for the server-side.
Express: A minimal and flexible Node.js web application framework.
MongoDB: A NoSQL database to store notes.
Mongoose: An ODM (Object Data Modeling) library for MongoDB and Node.js.
